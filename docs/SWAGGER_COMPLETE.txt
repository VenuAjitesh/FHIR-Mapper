## Key Features Now Documented

### ✅ Observation Components
```yaml
components:
  - observation: Systolic blood pressure
    valueQuantity: {value: 140, unit: mmHg}
    referenceRange: {low: {value: "90"}, high: {value: "120"}}
  - observation: Diastolic blood pressure
    valueQuantity: {value: 90, unit: mmHg}
    referenceRange: {low: {value: "60"}, high: {value: "80"}}
```

### ✅ Reference Ranges
```yaml
referenceRange:
  low: {value: "100", unit: "mg/dL", system: "http://unitsofmeasure.org"}
  high: {value: "200", unit: "mg/dL", system: "http://unitsofmeasure.org"}
```

### ✅ Age-Based Ranges
```yaml
referenceRange:
  age: {low: "18", high: "65"}
  low: {value: "0.0", unit: "mmol/L"}
  high: {value: "5.5", unit: "mmol/L"}
```
